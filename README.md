# WORLD STATE

Protótipo inicial de um jogo de grande estratégia e gerenciamento histórico global.

## Princípios

- Cobertura mundial completa para cada data/cenário, incluindo países, reinos, impérios, cidades-Estado, confederações, tribos, clãs, chefias, colônias, vassalos e outras entidades relevantes.
- Sistemas adaptados à época: economia, política, tecnologia, militarismo, diplomacia, espionagem e interface evitam anacronismos.
- IA emergente com memória, cultura, interesses, instituições e informação limitada por fog of war.
- O jogador pode agir por linguagem natural ou pelos controles manuais do mesmo motor de simulação.
- A História define o ponto de partida; a simulação define o futuro.

## Protótipo v0.1

- React + TypeScript + Vite.
- Interface moderna/minimalista em tema escuro.
- Mapa mundial interativo inicial.
- Controle de tempo: pausa, 1x, 2x, 4x, 8x e avanço de período.
- Modos de mapa iniciais.
- Interface simples/avançada.
- Conselheiro IA local de demonstração.
- Estado do jogo separado da camada visual.
